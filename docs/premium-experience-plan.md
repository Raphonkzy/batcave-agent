# Premium experience implementation plan

## Audit and reusable systems
React hash routes render Office, which owns live polling, overlays and the lazy R3F canvas. AppHeader and SideNav already provide a closed-by-default drawer, focus trap and fullscreen controls. Preserve these rather than create another shell. ThemeManor composes floor-specific procedural scenes. computeLayout owns shared boundaries, paths and placements. Batches groups geometry/material pairs; Crew animates shared instances using six bone transforms. ManorCamera owns OrbitControls and cancellable preset flights.

## Root causes
- Office mounts a centered empty-state over a viable scene on ordinary API failures and removes the scene while pending.
- Independent top overlays reserve no shared layout space; toolbar, help and quality controls can collide.
- Upper windows and ground windows use different aperture rules. Unify shell and opening generation for both levels.
- Roof slopes have no thickness or surface articulation. Preserve footprint-based roof planning.
- Grounds contain gate placeholders but no continuous estate boundary.
- Elevator is explicitly cylindrical tube geometry, despite existing navigation-supported vertical travel. Replace geometry without changing graph endpoints.
- Selection draws a ground wireframe. Use batched object-part surface overlays with private disposable materials; preserve shared originals.
- OrbitControls maps left and right to rotate, contradicting help. Reserve left for selection, right for screen-space pan, middle and Q/E for rotation.
- Human anatomy is rectangular and motion poses switch abruptly; keep instancing and add layered proportions and damped locomotion.

## Ordered delivery
1. Compact accessible resource status with retry/diagnostics; shared responsive toolbar and grouped navigation.
2. Shared two-floor aperture generation and trim; facade, roof and grounds refinement; architectural lift using existing travel.
3. Mesh-aware hover/selection and explicit input ownership; regress bindings and shared-material safety.
4. Modular rounded anatomy and role-specific gear, blended motion and restrained material/lighting improvements.
5. Unit regressions, full lint/types/build, rendered cross-scene input and responsive audits at 1920x1080, 1600x900, 1366x768 and smaller windows.

## Constraints
Pool remains south (+Z), main entrance and approach remain pool-facing. Preserve adaptive room layout, named identities, live API functionality, camera ownership and all routes. No new dependencies. Never claim screenshots alone prove structural integrity or claim software-renderer measurements represent desktop GPU performance. Elevator follows existing agent travel; do not imply unsupported vehicle entry or server-persisted building edits.
